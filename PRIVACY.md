# Privacy Notice

**Maintainer:** Amirali Yazdani  
**Application:** Multi-Pascal Mac

The current application processes source code and program input locally on the user's Mac. Source files are read or written through user-initiated file dialogs or explicit command-line paths. The project does not currently include analytics, advertising, telemetry, account registration, or a remote service for uploading source code.

Downloaded release files may be subject to the hosting provider's own logging and privacy practices. This notice describes the behavior of this repository's current implementation and should be reviewed if network features, analytics, crash reporting, or other data collection are added.

Questions about this notice can be directed to the maintainer through the contact method on Amirali Yazdani's GitHub profile.
