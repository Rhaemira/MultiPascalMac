# Security Policy

**Maintainer:** Amirali Yazdani

## Supported versions

Security fixes are developed against the latest published source on the `main` branch. No separate long-term-support release is currently maintained.

## Reporting a concern

Do not publish passwords, signing credentials, or exploitable details in a public issue. Contact the repository maintainer through the contact method listed on the maintainer's GitHub profile, and include the affected version, reproducible steps, and impact where possible.

The interpreter processes user-supplied source and input locally. Resource limits are present for selected operations, but this project is a teaching simulator and has not undergone a formal security audit. Do not use it as a sandbox for hostile programs or as a security boundary.
